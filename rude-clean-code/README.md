# Rude Clean Code

Early-stage, version-only distribution scaffold for a planned Clean Code /
SOLID-inspired plugin for the Rude Python linter. Currently exposes only
`VERSION`, read from installed distribution metadata.

See the
[repository README](https://github.com/Archont561/rude-clean-code#readme) and
[documentation](https://github.com/Archont561/rude-clean-code/blob/main/docs/README.md)
for setup, architecture, and the backlog specification.
