## Description

Outcome: consumers can enforce their own architecture with the plugin: dependency-direction rules (CC701, CC702, CC704) and design-pattern boundary rules (CC801-CC805) that are provably inert until configured with the consumer's modules, paths, and base classes, plus published Basic/Strict/Architecture profile snippets. Scope excludes inventing layers for the consumer; the generic plugin ships mechanisms, not opinions about a specific codebase. Target one session and one PR after m-1 lands.
