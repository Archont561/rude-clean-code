## Description

Outcome: the repository exists as an Archont561-style Pixi workspace with
one installable distribution, `packages/rude-clean-code/`, reduced to a
metadata-backed VERSION scaffold whose version is declared once in its
`pyproject.toml` and verified by a package-local BDD scenario. Scope is
the scaffold plus the backlog specification and decisions; no lint rules.
Target one session and one PR; the first rule milestone is assessed only
after this scaffold verifies end to end.
