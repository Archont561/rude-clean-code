# Rude Clean Code

An early-stage, planned Clean Code / SOLID-inspired plugin for the
[Rude](https://docs.rude.dev) Python linter. The repository is currently a
version-only scaffold: the single distribution under
[`packages/rude-clean-code/`](packages/rude-clean-code/) exposes only
`VERSION`, and no lint rules are implemented yet. Check the
[backlog](backlog/README.md), its specification
(`backlog/docs/`) and its decisions (`backlog/decisions/`) before proposing
work, and avoid presenting planned capabilities as finished.
